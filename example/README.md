# flutter_reels_video_example

Runnable demo for the [`flutter_reels_video`](../README.md) package: a fake
paginated API feeds `ReelVideo` pages (public sample `.mp4` URLs) into
`ReelsPagerView` so you can try swiping, autoplay/preload and
load-more-on-scroll on a real device or simulator.

## Run it

```sh
flutter pub get
flutter run
```
